## Fill answers and see marks later

1. [Download the browser practice ZIP](https://github.com/kapiltrip/RTL-to-GDS-Flow/raw/refs/heads/main/Assignments/Practice/Browser%20Practice%20-%20All%20Weeks.zip) and extract it.
2. Open **original-course.html** for the original assignments, or **possible-mcqs.html** for the 50-per-week practice sets, in Chrome.
3. Choose a week and select one option per question. Choices save in that browser when storage is available; you can change weeks and return later.
4. Choose **Finish attempt** to lock the selections. Marks stay hidden until you choose **Show marks**. The page shows only the score, without revealing correct answers.
5. Use **Begin new attempt** to try again while keeping the previous attempt. Use **Download answers backup** to keep a separate copy, and import that backup to continue elsewhere.

Automatic marks use the selections entered in the browser file. The PDFs also have fillable response controls for saving or printing your work. PDF selections and browser selections are separate. Nothing is submitted to NPTEL, and personal attempts are not saved in this Git repository.

Each question scores one point in this independent practice, with no negative marking. These practice marks are not an official NPTEL result or a statement of the final exam's marking policy.
