# Lecture frames and topic crops

[Resource guide](../README.md) · [Source register](../Sources.md) · [Complete handwritten pages](../Handwritten%20Index.md)

Images are organized as `Day NN/Lesson NN/`. Each daily note places a frame or handwritten crop beside its explanation and cites its lecture timestamp or original page identity. The full notebook pages remain in `../sources/handwritten`; a crop does not replace that preserved source.

Keep an existing image path when revising surrounding prose. Add a descriptive image filename and a source caption for a new frame, then record the capture in the source register. Use actual lecture images for source evidence; label any separately authored diagram as an explanation.

Figure links return to the day index in Markdown and to contents in exported PDFs. Rebuild the affected day after changing an image, and inspect the rendered figure and caption at readable scale. Capture hashes detect changed files, while a visual/source review checks whether the image supports the interpretation.
